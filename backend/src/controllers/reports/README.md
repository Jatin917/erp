# Reports Controllers

## Purpose
Configurable report generation using the field registry system.

## Responsibilities
- Report definition and execution
- Field selection from registry
- Export (where implemented)

## Dependencies
- registry/ (field definitions and cache)
- reports/ module
- requirePermission VIEW_REPORTS, EXPORT_REPORTS

## Public interfaces
/api/v1/reports
