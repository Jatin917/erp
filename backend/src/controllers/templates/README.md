# Templates Controllers

## Purpose
HTTP API for document template management (PDF templates, field mappings).

## Responsibilities
- CRUD for document templates
- Field mapping configuration
- Delegates to document-templates/ engine

## Dependencies
- document-templates/
- /api/v1/templates route
